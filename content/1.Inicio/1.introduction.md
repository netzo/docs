**Netzo** es un sistema ERP diseñado para **operar, gobernar y escalar** empresas industriales y comerciales de forma estructurada.

A diferencia de sistemas centrados solo en contabilidad o documentos, :br
Netzo está construido alrededor de **procesos reales**, **trazabilidad operativa** y **contexto completo de negocio**.

En Netzo:

- Los datos tienen estructura y significado
- Los procesos tienen estados y responsables
- Las decisiones impactan de forma coherente a todo el sistema

::note
Netzo no es un conjunto de módulos aislados. :br
Es un sistema integrado donde cada módulo cumple un rol claro dentro del ciclo del negocio.
::

---

## Cómo está organizado Netzo

El sistema se compone de **módulos especializados**, cada uno responsable de una capa específica de la operación.

Algunos módulos **definen reglas**, otros **ejecutan procesos**, y otros **analizan resultados**. :br
Juntos forman un flujo continuo, desde la configuración hasta la operación diaria.

---

## Módulos del sistema

A continuación se presentan los módulos principales de Netzo y el rol que cumple cada uno dentro del sistema:

::card-group
  :::card{icon="i-mdi-shield-crown" title="Administración" to="/administracion"}
  Capa de gobierno del sistema. Define usuarios, roles, permisos, estructura organizacional y reglas globales.
  :::

  :::card{icon="i-mdi-database" title="Datos Maestros" to="/datos-maestros"}
  Base estructural del sistema. Define productos, variantes, formatos, unidades y catálogos compartidos.
  :::

  :::card{icon="i-mdi-handshake" title="Ventas" to="/ventas"}
  Capa de relación comercial. Gestiona clientes, negocios, cotizaciones y órdenes de venta.
  :::

  :::card{icon="i-mdi-cart-arrow-down" title="Compras" to="/compras"}
  Capa de abastecimiento. Controla proveedores, solicitudes y órdenes de compra para garantizar suministro.
  :::

  :::card{icon="i-mdi-warehouse" title="Inventarios" to="/inventario"}
  Capa de control físico. Gestiona existencias por almacén, estados de stock y movimientos trazables.
  :::

  :::card{icon="i-mdi-factory" title="Producción" to="/produccion"}
  Capa de transformación. Ejecuta órdenes de producción y convierte materiales en productos terminados.
  :::

  :::card{icon="i-mdi-currency-usd" title="Finanzas" to="/finanzas"}
  Capa financiera. Gestiona facturación, cuentas por cobrar, cuentas por pagar y control económico.
  :::

  :::card{icon="i-mdi-chart-line" title="Reportes" to="/reportes"}
  Capa analítica. Permite visualizar desempeño operativo, comercial y financiero con datos reales.
  :::
::

## Cómo usar esta documentación

Esta documentación está organizada por módulos.

Te recomendamos:

1. Entender primero el **rol de cada módulo**
2. Leer las **introducciones** antes de entrar a guías operativas
3. Configurar correctamente **Administración y Datos Maestros**
4. Después, avanzar a los módulos operativos
