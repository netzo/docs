La documentación de Netzo está organizada para ayudarte a **encontrar la información correcta en el momento correcto**.

Cada sección tiene un propósito claro: algunas te ayudan a **entender cómo funciona el sistema**, otras a **hacer tareas específicas**, y otras a **consultar definiciones o reglas** cuando lo necesitas.

Esta estructura evita confusión y te permite avanzar más rápido, sin perder contexto.

---

## Tipos de guías disponibles

::card-group
  :::card{icon="i-mdi-lightbulb-on" title="Conceptos"}
  Explican **cómo funciona Netzo**. 
  Ideales para entender conceptos, modelos y decisiones del sistema.

  :br
  :::

  :::card{icon="i-mdi-format-list-checks" title="Guías prácticas"}
  Guías prácticas para **realizar tareas específicas** paso a paso.

  :::card{icon="i-mdi-book-open-variant" title="Glosario"}
  Definiciones precisas y técnicas. :br

  :::

## Cuándo usar cada tipo

| Necesitas…                  | Usa         |
| --------------------------- | ----------- |
| Entender cómo funciona algo | Explanation |
| Ejecutar una tarea concreta | How-To      |
| Confirmar una definición    | Reference   |

---

## Recomendación

Si eres nuevo en un módulo:

1. Empieza con **Explanation**
2. Luego usa **How-To**
3. Consulta **Reference** solo si tienes dudas puntuales
