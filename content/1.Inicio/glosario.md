Este glosario contiene términos y definiciones clave para entender el sistema ERP Netzo.
Puedes usar el buscador para encontrar definiciones específicas.

## Términos clave

- **Almacén**: Lugar físico o virtual donde se guarda el inventario. Ver [Almacenes](/inventarios-y-almacenes/conceptos/almacenes).
- **Inventario**: Conjunto de productos almacenados en un almacén. Ver [Inventarios](/inventarios-y-almacenes/conceptos/inventarios).
- **Lote**: Grupo de unidades de producto que comparten características comunes, como fecha de fabricación o proveedor. Ver [Lotes](/inventarios-y-almacenes/conceptos/lotes).
- **Número de serie**: Identificador único asignado a cada unidad individual de un producto. Ver [Números de serie](/inventarios-y-almacenes/conceptos/numeros-de-serie).
- **Segmento de inventario**: Clasificación operativa del inventario que define cómo puede utilizarse el stock sin alterar el total físico. Ver [Segmentos de inventario](/inventarios-y-almacenes/conceptos/segmentos).
- **Conteo cíclico**: Proceso de verificación y ajuste periódico del inventario para asegurar que los registros del sistema coincidan con la realidad física. Ver [Conteos cíclicos](/inventarios-y-almacenes/guias-practicas/ajustes/conteo-ciclico).
- **Conversión de inventario**: Proceso de transformar el inventario entre diferentes formatos sin alterar la cantidad total. Ver [Conversiones de inventario](/inventarios-y-almacenes/guias-practicas/ajustes/conversiones).
- **Variante de producto**: Diferentes versiones de un mismo producto que pueden variar en características como tamaño, color o empaque. Ver [Variantes de producto](/datos-maestros/variantes-de-producto).
- **Formato**: Unidad de medida o empaque en el que se presenta un producto. Ver [Formatos y unidades](/datos-maestros/formatos).
- **Trazabilidad**: Capacidad de rastrear el historial, la aplicación o la ubicación de un producto a lo largo de su ciclo de vida. Ver [Trazabilidad](/inventarios-y-almacenes/conceptos/trazabilidad).
- **Inventario físico**: Cantidad real de productos presentes en el almacén.
- **Inventario disponible**: Cantidad de inventario que puede ser utilizada o despachada.
- **Inventario reservado**: Cantidad de inventario comprometida para una operación futura.
- **Inventario bloqueado**: Cantidad de inventario que está temporalmente no utilizable.
- **ERP (Enterprise Resource Planning)**: Sistema de planificación de recursos empresariales que integra y gestiona las principales funciones de una empresa.
- **Módulo**: Componente especializado dentro del sistema ERP que cumple una función específica, como Ventas, Compras o Inventarios.
- **Proceso**: Conjunto de actividades o tareas que se realizan para lograr un objetivo específico dentro del sistema ERP.
- **Trazabilidad operativa**: Seguimiento detallado de las operaciones y movimientos dentro del sistema ERP para asegurar la coherencia y precisión de los datos.
- **Datos maestros**: Información estructural y fundamental que define productos, variantes, formatos y unidades dentro del sistema ERP.
- **Ajuste de inventario**: Corrección realizada al inventario para reflejar la realidad física, ya sea por errores, pérdidas o ganancias.
- **SKU (Stock Keeping Unit)**: Unidad de mantenimiento de stock, que representa una combinación específica de producto, variante, formato y lote/número de serie.
- **Operación atómica**: Evento que se realiza de manera completa e indivisible, asegurando que todas las partes del proceso se ejecuten correctamente o ninguna lo haga.
- **Estructura organizacional**: Configuración jerárquica y funcional de una empresa dentro del sistema ERP, que define roles, responsabilidades y permisos.
- **Rol**: Conjunto de permisos y responsabilidades asignadas a un usuario dentro del sistema ERP.
- **Permiso**: Autorización para realizar ciertas acciones o acceder a determinadas áreas dentro del sistema ERP.
- **Flujo continuo**: Secuencia ininterrumpida de procesos y actividades dentro del sistema ERP que asegura la coherencia y eficiencia operativa.
- **Contexto completo de negocio**: Visión integral de todas las operaciones, procesos y datos dentro del sistema ERP que permite una toma de decisiones informada y coherente.
- **Trazabilidad auditada**: Registro detallado y verificable de todas las operaciones y movimientos dentro del sistema ERP para asegurar la transparencia y responsabilidad.
- **Evento atómico**: Acción que se realiza de manera completa e indivisible, garantizando que todas las partes del proceso se ejecuten correctamente o ninguna lo haga.
- **Combinación específica**: Conjunto único de variante de producto, formato y lote/número de serie que define un SKU operativo.
- **Unidad base**: Medida estándar utilizada para cuantificar productos dentro del sistema ERP, que sirve como referencia para conversiones y ajustes.
- **Empaque**: Forma en que se presenta un producto para su almacenamiento, transporte o venta, que puede influir en su formato y unidad de medida.
- **Unidad de medida**: Sistema utilizado para cuantificar y describir la cantidad de un producto, como piezas, cajas o kilogramos.
- **Unidad de medida transaccional**: Unidad utilizada para registrar y gestionar transacciones de inventario dentro del sistema ERP, que puede diferir de la unidad base.
