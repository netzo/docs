# Cómo {{ acción concreta }}

Esta guía explica **cómo realizar {{ acción concreta }}** en Netzo, de forma segura y siguiendo el flujo operativo correcto.

Al finalizar esta guía podrás:

- Ejecutar la acción sin afectar otros almacenes
- Mantener la trazabilidad del inventario
- Evitar errores comunes de operación

::note
Esta es una **guía práctica**. 
Si necesitas entender el concepto detrás de esta acción, consulta primero [Cómo funciona Inventarios](/inventario).

:br

:br
::

---

## Antes de comenzar

Asegúrate de cumplir lo siguiente:

- Tener acceso al módulo **Inventarios**
- Contar con permisos para la acción que vas a ejecutar
- Saber **en qué almacén** vas a operar
- Tener identificada la **variante** correcta

::warning
Las acciones en inventario afectan existencias reales. :br
Verifica siempre el almacén antes de confirmar.
::

---

## Pasos

::steps{level="4"}
---------

#### Paso 1 · Accede al almacén correcto

Desde el módulo **Inventarios**, selecciona el almacén donde se realizará la operación.

Confirma que:

- El nombre del almacén es correcto
- Estás en el contexto correcto de inventario

#### Paso 2 · Inicia la acción

Haz clic en **{{ botón o acción principal }}** y selecciona el tipo de operación correspondiente.

Ejemplo:

- Entrada por compra
- Salida por venta
- Traspaso
- Ajuste manual

#### Paso 3 · Captura la información requerida

Completa los campos obligatorios:

- Variante
- Cantidad
- Unidad / formato (si aplica)
- Referencia o motivo

Adjunta documentos si es necesario.

#### Paso 4 · Revisa y confirma

Antes de confirmar:

- Verifica cantidades
- Verifica el almacén
- Revisa el impacto esperado

Haz clic en **Confirmar** para ejecutar la acción.
::

---

## Resultado esperado

Al completar los pasos correctamente:

- El inventario del almacén se actualiza
- El movimiento queda registrado
- La acción queda auditada
- Otros almacenes no se ven afectados

## Errores comunes

- Operar en el almacén incorrecto
- Usar una variante equivocada
- Confundir formato con unidad base
- Confirmar sin revisar cantidades

::tip
Si algo no cuadra después de la operación, revisa el historial del almacén antes de hacer ajustes.
::

## Relación con otros procesos

Esta acción puede estar relacionada con:

- Entradas o salidas en otros almacenes
- Órdenes de compra
- Órdenes de venta
- Producción
- Traspasos
