# Inventario en almacén

Esta vista muestra **el estado real del inventario** para un almacén específico.

---

## Estados clave

| Estado        | Significado  |
| ------------- | ------------ |
| En existencia | Total físico |
| Reservado     | Comprometido |
| Retenido      | Bloqueado    |
| Disponible    | Usable       |

---

## Error común

> Confundir existencia con disponibilidad.

Disponible = Existencia − Reservas − Retenciones
