Esta guía explica **cómo registrar una eliminación de inventario** para dar de baja existencias que **ya no pueden utilizarse ni recuperarse**.

Una eliminación **reduce el inventario real del almacén** y deja un movimiento auditado en el sistema.

::warning
Una eliminación es **definitiva**.
Verifica cuidadosamente la información antes de confirmar.
::

## Antes de comenzar

Asegúrate de:

- Estar en el **almacén correcto**
- Tener permisos para **eliminaciones**
- Conocer el **motivo real** de la baja
- Confirmar que el producto **ya no existe o no es aprovechable**
- Contar con evidencia si aplica (fotografías, reportes, actas)

---

## Pasos para registrar una eliminación

::steps{level="4"}

#### Ve a **Inventarios → Almacenes → (Selecciona un almacén) → Eliminaciones**

Haz clic en **Crear** para abrir el formulario de eliminación.

---

#### Selecciona la variante y formato

Completa los campos:

- **Variante de producto**
  Selecciona la variante exacta que será eliminada.

- **Formato**
  Indica el formato en el que se encuentra el inventario
  (individual, caja, saco, bobina, etc.).

::note
La eliminación siempre se registra sobre una **combinación específica de variante + formato**.
::

---

#### Define el segmento y la cantidad

- **Segmento**
  Selecciona desde qué estado se eliminará el inventario
  (normalmente **Disponible** o **Retenido**).

- **Cantidad**
  Ingresa la cantidad real que será dada de baja.

::tip
La cantidad no puede exceder el inventario existente en ese segmento.
::

---

#### Indica la razón de eliminación

Selecciona una **Razón** que explique por qué el inventario se elimina.

Ejemplos comunes:
- Daño
- Caducidad
- Merma
- Producto inservible
- Pérdida confirmada

Este campo es **obligatorio** y forma parte de la trazabilidad.

---

#### Adjunta evidencia y comentarios (opcional)

Puedes agregar:
- Fotografías
- Reportes
- Actas
- Observaciones operativas

Esto es especialmente recomendable en:
- Mermas
- Daños
- Caducidades
- Auditorías internas

---

#### Confirma la eliminación

Haz clic en **Confirmar** para ejecutar la eliminación.

::warning
Al confirmar:
- El inventario se reduce inmediatamente
- Se genera un movimiento de inventario
- La acción no puede deshacerse
::

::

---

## Qué sucede al confirmar

Al confirmar una eliminación, el sistema:

- Reduce el inventario del almacén
- Afecta el segmento seleccionado
- Registra un **movimiento auditable**
- Conserva trazabilidad por:
  - Usuario
  - Fecha
  - Razón
  - Variante y formato

---

## Resultado esperado

Después de una eliminación correcta:

- El inventario disminuye
- El stock refleja la realidad física
- El movimiento queda registrado para auditoría
- Los reportes se actualizan automáticamente

---

## Cuándo NO usar eliminaciones

::warning
No utilices eliminaciones para:
- Corregir diferencias de conteo
- Cambiar formato de empaque
- Cambiar el estado del inventario
- Transferir inventario
- Simular salidas operativas
::

Para esos casos utiliza:
- **Conteos cíclicos**
- **Conversiones**
- **Cambios de estado**
- **Salidas**

---

## Errores comunes

- Eliminar inventario desde el almacén incorrecto
- No validar variante o formato
- Usar eliminaciones para corregir errores de conteo
- No documentar el motivo
- Eliminar inventario que aún podía recuperarse

::tip
Si el inventario aún existe pero no puede usarse,
primero muévelo a **Retenido** y elimina solo cuando esté confirmado.
::
