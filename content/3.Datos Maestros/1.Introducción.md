El módulo de **Datos Maestros** es la **capa estructural** de Netzo. :br
Aquí se define **qué existe en el sistema** y **cómo se representa la realidad del negocio**.

En Datos Maestros **no se ejecutan operaciones diarias**. :br
Se construyen los elementos que todos los demás módulos utilizan para operar.

::note
Si Ventas, Compras o Inventarios definen **lo que sucede**,
Datos Maestros define **con qué elementos puede suceder**.
::

---

## ¿Para qué sirve el módulo de Datos Maestros?

Datos Maestros permite a la organización:

- Definir productos y servicios de forma estructurada
- Crear variantes operables y específicas
- Establecer formatos comerciales y logísticos
- Unificar unidades de medida y catálogos
- Evitar ambigüedad en inventarios, costos y ventas

Es el punto donde **la realidad del negocio se traduce en datos consistentes**.

---

## Qué se configura aquí (y qué no)

### Sí se configura en Datos Maestros

- Productos
- Variantes de producto
- Formatos (cajas, paquetes, bobinas, etc.)
- Unidades de medida
- Categorías y atributos
- Catálogos reutilizables

### No se hace en Datos Maestros

- Mover inventario
- Cotizar o vender
- Comprar o recibir mercancía
- Ejecutar producción

::note
Datos Maestros **no es un módulo operativo**. :br
Es un módulo de **definición y estandarización**.

:br
::

---

## Cómo se relaciona con el resto de Netzo

Datos Maestros alimenta directamente a todos los módulos operativos.

| Módulo      | Qué recibe desde Datos Maestros      |
| ----------- | ------------------------------------ |
| Inventarios | Variantes, unidades, formatos        |
| Producción  | Materiales, productos fabricables    |
| Compras     | Artículos comprables                 |
| Ventas      | Artículos vendibles y presentaciones |
| Finanzas    | Base para valorización y costos      |
| Reportes    | Dimensiones consistentes de análisis |

---

## Principios clave del módulo

### 1. Definición antes que movimiento

Un producto mal definido se mueve mal en todo el sistema.

Datos Maestros existe para:

- Prevenir duplicidades
- Evitar confusión operativa
- Garantizar consistencia en toda la empresa

---

### 2. Variantes sobre productos genéricos

En Netzo, **todo lo que se opera es una variante**, no un concepto abstracto.

Esto permite:

- Inventarios precisos
- Costeo correcto
- Ventas sin ambigüedad

---

### 3. Formatos como puente con la realidad

Los formatos permiten representar cómo el negocio **compra, vende y maneja** productos en la vida real.

::warning
Modificar variantes o formatos con operación activa
puede afectar inventarios y reportes históricos.
::

---

## ¿Quién debería usar este módulo?

El módulo de Datos Maestros está pensado para:

- Responsables de operación
- Planeación y control
- Administradores del sistema
- Usuarios clave de inventarios y ventas
