El módulo de **Compras** es la **capa de abastecimiento** de Netzo. :br
Aquí se transforman las necesidades internas en **suministro controlado y trazable**.

Compras no reacciona a la urgencia. :br
Organiza, valida y formaliza cómo la empresa adquiere insumos, materiales y servicios.

::note
Si Ventas representa la demanda,
Compras representa la respuesta estructurada a esa demanda.
::

---

## ¿Para qué sirve el módulo de Compras?

Compras permite a la organización:

- Centralizar proveedores y condiciones
- Controlar solicitudes internas
- Formalizar órdenes de compra
- Dar trazabilidad al abastecimiento
- Proteger costos y continuidad operativa

Es el punto donde **la necesidad se convierte en compromiso con un proveedor**.

---

## Qué se configura aquí (y qué no)

### Sí se hace en Compras

- Gestión de proveedores
- Solicitudes de compra
- Órdenes de compra
- Seguimiento de abastecimiento
- Recepción de mercancía (en coordinación con Inventarios)

### No se hace en Compras

- Definir productos base
- Vender o cotizar
- Ajustar inventarios manualmente
- Ejecutar pagos (finanzas)

::note
Compras **no ejecuta inventario**,
pero **es el origen de muchas entradas**.

:br
::

---

## Cómo se relaciona con el resto de Netzo

Compras conecta necesidad, proveedor e inventario.

| Módulo         | Relación con Compras                  |
| -------------- | ------------------------------------- |
| Inventarios    | Entradas por almacén                  |
| Producción     | Insumos y materiales necesarios       |
| Ventas         | Reabastecimiento para cumplir pedidos |
| Finanzas       | Cuentas por pagar y control de costos |
| Datos Maestros | Artículos comprables                  |

---

## Principios clave del módulo

### 1. Comprar con contexto, no con urgencia

Compras existe para **anticipar**, no solo reaccionar.

Una compra bien estructurada reduce:

- Faltantes
- Compras duplicadas
- Sobreprecios

---

### 2. Separación entre solicitar y autorizar

Netzo permite separar:

- Quién solicita
- Quién aprueba
- Quién recibe

Esto crea control y trazabilidad.

---

### 3. Abastecimiento trazable

Cada compra deja rastro:

- Quién la solicitó
- A qué proveedor
- Para qué se necesita
- Dónde impacta

::warning
Órdenes de compra mal definidas
afectan inventario, costos y finanzas.
::

---

## ¿Quién debería usar este módulo?

El módulo de Compras está pensado para:

- Equipos de compras
- Planeación y operaciones
- Almacenes (recepción)
- Finanzas (control del gasto)
