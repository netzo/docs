# Ventas

El módulo de **Ventas** es la **capa de relación comercial** de Netzo. :br
Aquí la demanda del cliente se convierte en **compromisos claros para la empresa**.

Ventas no solo registra pedidos. :br
Organiza la relación con el cliente y da inicio al flujo operativo y financiero.

::note
Si Compras responde a la necesidad interna,
Ventas representa el compromiso externo.
::

---

## ¿Para qué sirve el módulo de Ventas?

Ventas permite a la organización:

- Centralizar la información del cliente
- Dar contexto a cada negociación
- Gestionar negocios y oportunidades
- Formalizar acuerdos mediante órdenes de venta
- Iniciar el impacto en inventarios y finanzas

Es el punto donde **la promesa al cliente se vuelve obligación interna**.

---

## Qué se gestiona aquí (y qué no)

### Sí se hace en Ventas

- Gestión de clientes y cuentas
- Negocios y oportunidades
- Cotizaciones
- Órdenes de venta
- Seguimiento comercial

### No se hace en Ventas

- Definir productos base
- Mover inventario manualmente
- Ejecutar producción
- Registrar pagos

::note
Ventas inicia procesos,
pero no los ejecuta todos.

:br
::

---

## Cómo se relaciona con el resto de Netzo

Ventas es el origen del ciclo operativo.

| Módulo         | Relación con Ventas                  |
| -------------- | ------------------------------------ |
| Inventarios    | Reservas y surtido por almacén       |
| Producción     | Fabricación de lo vendido            |
| Compras        | Reabastecimiento para cumplir ventas |
| Finanzas       | Facturación y cuentas por cobrar     |
| Datos Maestros | Artículos vendibles                  |

---

## Principios clave del módulo

### 1. El cliente como eje

Toda la información gira alrededor del cliente:
negocios, acuerdos, historial y documentos.

---

### 2. Negocios antes que documentos

Netzo prioriza:

- Contexto
- Historial
- Seguimiento

Antes que solo PDFs.

---

### 3. Vender con respaldo real

Cada venta debe:

- Tener inventario disponible
- Tener reglas claras
- Tener impacto trazable

---

## ¿Quién debería usar este módulo?

El módulo de Ventas está pensado para:

- Equipos comerciales
- Atención a clientes
- Dirección comercial
- Planeación y operaciones
